这是 Lin 的技能仓库：把反复用到的能力沉淀成可复用的技能，每个技能一个文件夹，入口是 SKILL.md，开头 YAML frontmatter 写 name 和 description(何时使用)。

## 目录

| 技能 | 用途 | 路径 |
| --- | --- | --- |
| 编码+概念记忆生成 | 把「编码物 + 概念」变成好记、能准确还原的记忆画面；一条一条生成 | `skills/mnemonic-encoding/` |

## 新增技能

新建 `skills/<kebab-slug>/SKILL.md`，按同样格式写，配套示例放 `examples/`，并在目录表里加一行。
