# 编码 + 概念 → 记忆内容

核心能力：把一个编码物和一个概念撞成一个具体、好记、能唯一还原到该概念的画面。编码物由用户给出，原样使用；用户没给时才从常见中文数字编码里取一个具体好画的物，并告诉用户。

好画面的公式：编码物和关键词之间发生一个具体动作，回忆路径是 编码物 → 画面 → 关键词 → 概念。失败的根源几乎总是「在描述意思」：画面能对应多个概念，回忆时分不清。

## 0. 一条一条来（必须）
批量一次生成几十条，越往后越敷衍。每个「编码物 + 概念」都单独走完整流程：标拼音 → 至少列 6 个候选 → 逐个过关卡 → 写 2 个画面挑 1 个 → 自检还原 → 定稿，然后才开始下一条。后面的条目和前面的条目同样深度；发现自己在缩短推理就停下重做。即使用户说不用中途确认、一口气做完，也必须一条一条做，绝不在一次输出里连写多条；不需要确认时就逐条做完再整体交付。重做或修改已有条目时同样逐条走完整流程，不能只改几个字凑数。用户没说可以不确认时，条目多就分批交付，每批不超过 5–8 条，看过再继续。

## 1. 分类型
- 自带故事的（成语、计谋、典故）：拆出 2–4 个能画的字用情节演出来，画不出的字补谐音钩子（围魏救赵：围、喂、救、照）。
- 本身具体的概念（问答、路径、交易）：编码物直接演出这个动作。
- 抽象概念（状态、属性、认知）：必须先找关键词（第 2 步），不能只描述意思。

## 2. 找关键词
逐字标拼音（多音字查词典），每种办法至少列 3 个候选：
- 整词谐音的真词：村寨→存在、小狮→消失、拜托→摆脱。
- 逐字谐音组成自然两字小句（主谓、动宾、偏正）：羊抬→样态、撞台→状态、剪梢→减少、数星→属性。
- 同音真词太抽象时望文生义：出线＝从葫芦口抽出一根线。
- 英语表达的谐音可作第二钩子；there be → bee。
- 代表物（公正→天平）最后才用，最容易还原成近义词。
音近分级（逐字）：L0 全同；L1 只差声调；L2 声母或韵母恰好一处近音（z/zh c/ch s/sh n/l f/h r/l；an/ang en/eng in/ing ian/iang uan/uang）。其余不合格；整词最多一个 L2。

## 3. 硬关卡（任一不过就丢弃）
- 真词：词典里的词，或不用解释就懂的两字小句。不许从长词截字（太空舱→太），不许拼两样不相干的东西（羊太、鼠星），不用生僻字。
- 不硬凑：关键词必须是现成说法，或者日常真会说、说得通的组合。为了谐音临时拼出来的动宾小句不算（掷月：没人往月亮上扔东西；认枝、沉索、坐拥渔坞同理）。判断方法：脱离这个概念，单独说出这个词，别人会不会觉得奇怪？会就丢弃。优先找成语、俗语、民间说法、常见物件（指月→制约，还连着"指月亮会割耳朵"的禁忌）。
- 字数和顺序对齐，逐字在 L2 以内。
- 能画：看得见的实物或身体动作；气味、心理、抽象名词不行。
- 看图命名：别人只看画面，第一反应说出的就是这个词（端砚会被叫成砚台，不合格）。
- 画面里原样写出关键词，且它是核心动作或物体。
- 编码物是主语或宾语，和关键词有物理接触，不当背景。
- 关键词不能和其他编码物撞车，同一套里不重复；画面里不出现别的编码物。
排序：音越近越好 > 有动作优先于静物 > 越常用越好。关键词的动作顺带体现概念意思更好（小狮钻进耳朵不见了→消失），但意思只辅助，不替代关键词。

## 4. 写画面
模板：编码物 + 关键词动作 + 一个感官细节（声音、气味、触感），一个镜头，约 30–40 字，结尾用破折号点出「关键词，概念」。夸张适度，重点是和同组其他条不雷同。
例：5 钩子 状态 → 大铁钩甩出去撞台，舞台木板「咣」地裂开——撞台，状态。

## 5. 自检与兜底
- 不看答案，从画面能否还原到唯一的概念？不能就重写。
- 结尾不能是「全是 X」「X 开机」这种空话。
- 再查一遍关键词是不是硬凑的：单独念出来别扭、要靠画面才说得通，就重找；实在找不到，宁可直接画概念本身，也不要硬凑词。
- 找不到合格关键词就标「需人工」，附 2–3 个最接近的候选，绝不硬凑。
- 列出不够稳的条目（只靠一个字同音，或只靠意思还原），请用户挑。

## 目录 / 分类的记忆锚
记忆锚 = 编码物 × 目录：每个子类一个锚，叶子列在下面，不写进故事。目录来自数据源时，先核对子类名和叶子与数据一致。

```
大类名 cat-id

1. 编码物 子类名
   画面——关键词，子类名

叶子, 叶子, 叶子
```
